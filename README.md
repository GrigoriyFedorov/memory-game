# Memory Game

Игра на поиск пар: открывай карточки, запоминай их расположение и найди все 8 пар за наименьшее число ходов.

**Деплой:** https://grigoriyfedorov.github.io/memory-game/

## Правила

* На поле 16 карточек — 8 пар одинаковых изображений. При загрузке страницы и каждой новой игре они перемешиваются.
* За ход открываются две карточки. Совпавшая пара остаётся открытой, несовпавшая закрывается через секунду.
* Пока несовпавшая пара открыта, другие карточки выбрать нельзя.
* Когда найдены все пары, открывается окно победы с количеством ходов, а результат попадает в таблицу лидеров.
* Таблица лидеров хранит 10 лучших результатов в `localStorage`: меньше ходов — выше место, при равенстве выше более ранняя игра.

## Возможности

* Вся разметка создаётся из JavaScript через `document.createElement` — в `<body>` файла `index.html` расположен только `<script>`.
* Общий компонент модального окна для окна победы и таблицы лидеров: закрытие кнопкой, кликом по фону или клавишей Escape, блокировка прокрутки под окном.
* Адаптивная вёрстка от 320px, 3D-анимация переворота карточек.

## Локальный запуск

Так как проект использует нативные ES6-модули, открытие файла напрямую через `file://` блокируется политикой CORS браузера.
Для работы нужен локальный сервер.

1. Клонируйте репозиторий:
   ```bash
   git clone https://github.com/GrigoriyFedorov/memory-game.git
   cd memory-game
   ```

2. Запустите проект:
   * **Через VS Code:** Откройте папку проекта в редакторе и запустите `index.html` с помощью расширения **Live Server**.
   * **Через консоль:** Запустите любой локальный сервер, например `npx serve` или `python -m http.server`.
